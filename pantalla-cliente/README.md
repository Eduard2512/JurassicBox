# Pantalla del cliente (segundo monitor)

1. Abrir `operador.html` en Chrome/Edge (monitor del colaborador).
2. Clic en **Abrir pantalla del cliente**, arrastrar esa ventana al segundo monitor y hacer **doble clic** para pantalla completa.
3. El colaborador agrega productos (clic o código/escáner + Enter); el cliente ve lista y total en vivo.
4. **Finalizar venta** muestra "Gracias" y luego vuelve a inicio; tras X segundos sin venta se muestra publicidad/cartelera.
5. Catálogo, publicidad y tiempos se editan en *Configuración* (se guardan en el navegador).

Funciona sin internet y sin TumiSoft. Ambas ventanas deben abrirse en el mismo navegador.
