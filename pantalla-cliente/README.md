# Pantalla del cliente (segundo monitor) · Movie Time

1. Abrir `operador.html` en Chrome/Edge (monitor del colaborador).
2. Clic en **Abrir pantalla del cliente**, arrastrar esa ventana al segundo monitor y hacer **doble clic** para pantalla completa (diseñada para 1920x1080).
3. Sin productos: publicidad a pantalla completa en rotación. Al agregar el primer producto aparece el detalle, las fotos y el total.
4. **Finalizar venta** muestra "Gracias" y luego vuelve a la publicidad.

## Personalizar
- Fotos de producto: `productos/<codigo>.webp` (sin foto se muestra el logo).
- Publicidad: imágenes 1920x1080 en `publicidad/`, agregadas en *Configuración* del panel (una por línea: `;;publicidad/archivo.jpg`).
- Catálogo, precios y contenido de combos: *Configuración* del panel.
